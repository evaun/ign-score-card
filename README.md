# IGN 中国评分卡生成器

IGN 中国评分卡生成工具，用于生成游戏评测评分卡图片。

## 功能

- 填写游戏封面、名称、评分、优缺点、总结等信息
- 实时预览评分卡效果
- 支持横版/竖版 PNG 导出

## 在线访问

[https://igncncard.netlify.app/](https://igncncard.netlify.app/)

## 本地使用

直接用浏览器打开 `index.html` 即可，无需服务器。

## 注意

此工具为IGN中国员工设计，仅为工作需求使用，第三方使用者生成的图片不代表IGN中国官方见解，官方评分请参见官网https://www.ign.com.cn/
